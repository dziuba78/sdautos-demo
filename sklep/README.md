# Dane do sklepu autocolor.pl

Ten katalog to dane produktów do sklepu **autocolor.pl**, nie cennik i nie stan magazynu.

Plik `pigmenty-autocolor-2k.json` zawiera 89 tonerów Nexa Autocolor 2K: kod, nazwę, grupę, opis na kartę produktu i miejsce na zdjęcie.

Zdjęcia wrzuca się obok strony sklepu jako `public/assets/images/pigmenty/KOD.webp` (albo jpg, jpeg, png), na przykład `P420-905.webp`.
